# MediLab — Medical Laboratory Frontend

## Structure
MediLab/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
└── README.md

## Run
Open index.html directly in Chrome, or open the folder in VS Code and use Live Server.

## Included
- Modern medical/diagnostic laboratory UI
- Test search
- Popular test buttons
- Diagnostic test categories
- Health packages
- Appointment booking form
- Home sample collection option
- Digital report section
- About/quality section
- Patient testimonials
- FAQ accordion
- Contact form
- Responsive mobile navbar
- Toast notifications
- Back-to-top button

This is frontend-only. Appointment/contact/report actions are demo UI and are not connected to a database or real laboratory system. Images are loaded from Unsplash URLs.
