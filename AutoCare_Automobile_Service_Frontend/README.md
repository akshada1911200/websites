# AutoCare — Automobile Service Frontend

## Files
- `index.html` — complete website structure
- `css/style.css` — responsive UI styling
- `js/script.js` — mobile menu, FAQ accordion, booking form UI, toast, back-to-top and active navigation

## Run
Open `index.html` directly in a browser, or use VS Code Live Server.

## Notes
This is frontend-only. The booking form currently shows a success notification and does not save data to a database.
The vehicle images use external Unsplash image URLs, so an internet connection is needed for those images.
