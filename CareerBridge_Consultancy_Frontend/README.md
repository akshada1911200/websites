# CareerBridge — Consultancy Frontend

A modern, responsive frontend-only sample website for a career/consultancy company.

## Included
- Responsive landing page
- Sticky navigation + mobile menu
- Hero section
- Career consultancy services
- Statistics
- "How It Works" process
- Testimonials / success stories
- Consultation booking form (frontend demo only)
- About section
- Footer
- Scroll reveal animations
- Google Fonts

## Folder Structure

career_consultancy_frontend/
├── index.html
├── README.md
├── css/
│   └── style.css
└── js/
    └── script.js

## How to Run

1. Extract the ZIP.
2. Open `index.html` in Chrome/Edge.
3. For the best development experience, open the folder in VS Code and use Live Server.

## Important
This is a frontend-only sample. The consultation form does not send data to a server. You can later connect it to Django, Flask, PHP, Node.js, Firebase, etc.

The company name/content is sample content created for a project demonstration and is not an official CareerBridge website.
