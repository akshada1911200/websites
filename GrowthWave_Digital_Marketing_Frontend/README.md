# GrowthWave Digital Marketing — Frontend

A modern frontend-only digital marketing agency website sample.

## Stack
- HTML5
- CSS3
- Vanilla JavaScript
- Google Fonts

## Included sections
- Responsive navigation
- Hero section with marketing dashboard visual
- Trusted brand strip
- Digital marketing services
- Performance metrics
- Case studies
- Marketing process
- Client testimonial
- Strategy-call contact form
- Responsive footer
- Mobile navigation
- Small interactive process section
- Frontend-only form confirmation

## Run
Extract the ZIP and open `index.html` in a browser.

For development, open the folder in VS Code and use Live Server.

## Note
This is a sample/demo frontend. GrowthWave is used as a fictional/sample brand concept; the content and metrics are placeholders and are not claims about a real company.
