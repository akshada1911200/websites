# Nestora — Real Estate Frontend

## Project structure
Nestora/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
└── README.md

## Run
Open `index.html` in Chrome or use VS Code Live Server.

## Included
Responsive premium real-estate UI, property search, featured listings, property categories, about section, agents, testimonials, FAQ accordion, contact form, mobile navigation, favorites, toast notifications and back-to-top button.

## Backend
This is frontend-only. Search and contact forms are UI demonstrations and do not save data.
Images are loaded from Unsplash URLs, so internet is needed for the photographs.
